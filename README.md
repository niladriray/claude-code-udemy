# Lifting Diary

A workout tracking application built with modern web technologies.

## Tech Stack

- **[Next.js](https://nextjs.org)** — React framework with App Router, server components, and server actions
- **[Clerk](https://clerk.com)** — Authentication and user management
- **[Neon](https://neon.tech)** — Serverless Postgres database
- **[Drizzle](https://drizzle.team)** — TypeScript ORM for type-safe database queries and migrations
- **[shadcn/ui](https://shadcn.com)** — Accessible, customizable UI component library built on Radix UI and Tailwind CSS
- **[Vercel](https://vercel.com)** — Deployment and hosting platform

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
